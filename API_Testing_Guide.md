## Доступ к Swagger UI

1. Запустите API проект с помощью команды `dotnet run --project DistrictStatisticsManagement.Api` или через Visual Studio
2. Откройте браузер и перейдите по адресу [http://localhost:5000/swagger](http://localhost:5000/swagger)
3. Вы увидите интерфейс Swagger UI с доступными эндпоинтами API

## Инициализация тестовых данных

Перед началом тестирования необходимо инициализировать тестовые данные:

1. В Swagger UI найдите раздел **DataInitialization**
2. Разверните эндпоинт `POST /api/DataInitialization/initialize`
3. Нажмите кнопку **Try it out**
4. Нажмите кнопку **Execute**
5. Проверьте, что получен ответ с кодом 200 и сообщением "Test data initialized successfully"

Теперь в системе созданы тестовые данные:
- 7 предприятий
- 5 поставщиков
- 15 поставок

## Тестирование CRUD операций

### Предприятия (Enterprises)

#### Получение всех предприятий (Read - R)

1. В Swagger UI найдите раздел **Enterprise**
2. Разверните эндпоинт `GET /api/Enterprise`
3. Нажмите кнопку **Try it out**
4. Нажмите кнопку **Execute**
5. Проверьте, что получен ответ с кодом 200 и списком предприятий в формате JSON

Пример ответа:
```json
[
  {
    "registrationNumber": "E001",
    "industryType": 4,
    "name": "ООО Стройматериалы",
    "address": null,
    "phone": null,
    "ownershipType": 2,
    "employeeCount": 0,
    "totalArea": 0,
    "supplies": [
      {
        "id": 4,
        "enterpriseRegistrationNumber": "E001",
        "supplierId": 4,
        "productName": "Цемент",
        "quantity": 2000,
        "supplyDate": "2023-02-20T00:00:00"
      },
      {
        "id": 10,
        "enterpriseRegistrationNumber": "E001",
        "supplierId": 4,
        "productName": "Песок",
        "quantity": 3000,
        "supplyDate": "2023-04-20T00:00:00"
      }
    ]
  },
  // ... другие предприятия
]
```

#### Получение предприятия по регистрационному номеру (Read - R)

1. В Swagger UI найдите раздел **Enterprise**
2. Разверните эндпоинт `GET /api/Enterprise/{registrationNumber}`
3. Нажмите кнопку **Try it out**
4. В поле **registrationNumber** введите `E001`
5. Нажмите кнопку **Execute**
6. Проверьте, что получен ответ с кодом 200 и информацией о предприятии в формате JSON

#### Создание нового предприятия (Create - C)

1. В Swagger UI найдите раздел **Enterprise**
2. Разверните эндпоинт `POST /api/Enterprise`
3. Нажмите кнопку **Try it out**
4. В поле Request body введите данные нового предприятия:

```json
{
  "registrationNumber": "E008",
  "industryType": 3,
  "name": "ООО ТехноПром",
  "address": "г. Москва, ул. Технологическая, 42",
  "phone": "+7 (495) 123-45-67",
  "ownershipType": 2,
  "employeeCount": 150,
  "totalArea": 5000
}
```

5. Нажмите кнопку **Execute**
6. Проверьте, что получен ответ с кодом 201 (Created) и данными созданного предприятия

#### Обновление предприятия (Update - U)

1. В Swagger UI найдите раздел **Enterprise**
2. Разверните эндпоинт `PUT /api/Enterprise/{registrationNumber}`
3. Нажмите кнопку **Try it out**
4. В поле **registrationNumber** введите `E008`
5. В поле Request body введите обновленные данные предприятия:

```json
{
  "registrationNumber": "E008",
  "industryType": 3,
  "name": "ООО ТехноПром Обновленный",
  "address": "г. Москва, ул. Технологическая, 42",
  "phone": "+7 (495) 123-45-67",
  "ownershipType": 2,
  "employeeCount": 200,
  "totalArea": 6000
}
```

6. Нажмите кнопку **Execute**
7. Проверьте, что получен ответ с кодом 204 (No Content)

#### Удаление предприятия (Delete - D)

1. В Swagger UI найдите раздел **Enterprise**
2. Разверните эндпоинт `DELETE /api/Enterprise/{registrationNumber}`
3. Нажмите кнопку **Try it out**
4. В поле **registrationNumber** введите `E008`
5. Нажмите кнопку **Execute**
6. Проверьте, что получен ответ с кодом 204 (No Content)

## Очистка данных

После завершения тестирования можно очистить все данные:

1. В Swagger UI найдите раздел **DataInitialization**
2. Разверните эндпоинт `POST /api/DataInitialization/clear`
3. Нажмите кнопку **Try it out**
4. Нажмите кнопку **Execute**
5. Проверьте, что получен ответ с кодом 200 и сообщением "All data cleared successfully"

## Проверка результатов

После выполнения всех операций CRUD и аналитических запросов, вы можете проверить, что данные корректно сохраняются и обрабатываются:

1. Получите список всех предприятий (`GET /api/Enterprise`) и убедитесь, что созданное вами предприятие присутствует в списке (если вы не удалили его)
2. Получите список всех поставщиков (`GET /api/Supplier`) и убедитесь, что созданный вами поставщик присутствует в списке
3. Получите список всех поставок (`GET /api/Supply`) и убедитесь, что созданная вами поставка присутствует в списке
4. Выполните аналитические запросы и убедитесь, что результаты соответствуют ожиданиям

Если все тесты прошли успешно, значит API работает корректно и данные правильно хранятся в памяти в виде коллекций.

## Тестирование через Visual Studio

### Настройка и запуск проекта в Visual Studio

1. Откройте решение `DistrictStatisticsManagement.sln` в Visual Studio
2. Установите проект `DistrictStatisticsManagement.Api` как стартовый проект:
   - Щелкните правой кнопкой мыши на проекте `DistrictStatisticsManagement.Api` в обозревателе решений
   - Выберите пункт "Назначить стартовым проектом"
3. Запустите проект, нажав клавишу F5 или кнопку "Запустить" на панели инструментов
4. Visual Studio запустит проект и автоматически откроет браузер со Swagger UI

### Тестирование CRUD операций вручную через Visual Studio

#### Инициализация тестовых данных

1. Откройте файл `Controllers/DataInitializationController.cs` в Visual Studio
2. Изучите метод `InitializeTestData()`, чтобы понять, какие тестовые данные создаются
3. Запустите проект и используйте Swagger UI для вызова метода инициализации, как описано выше

#### Тестирование операций Create (Создание)

1. Откройте соответствующий контроллер в Visual Studio (например, `EnterpriseController.cs` для предприятий)
2. Изучите метод `CreateEnterprise(Enterprise enterprise)` для понимания логики создания
3. Запустите проект и используйте Swagger UI для создания новой записи
4. Установите точку останова (breakpoint) в методе создания, чтобы отследить выполнение кода:
   - Щелкните на серой полосе слева от строки кода, где вы хотите установить точку останова
   - Запустите проект в режиме отладки (F5)
   - Выполните запрос на создание через Swagger UI
   - Когда выполнение кода достигнет точки останова, Visual Studio приостановит выполнение
   - Используйте окна "Локальные переменные" и "Контрольные значения" для проверки данных
   - Нажмите F10 для пошагового выполнения или F5 для продолжения выполнения

#### Тестирование операций Read (Чтение)

1. Откройте соответствующий контроллер в Visual Studio
2. Изучите методы получения данных (например, `GetAllEnterprises()` или `GetEnterprise(string registrationNumber)`)
3. Установите точки останова в этих методах
4. Запустите проект в режиме отладки и выполните запросы через Swagger UI
5. Когда выполнение достигнет точки останова, проверьте:
   - Содержимое репозитория (переменная `_repository`)
   - Результаты запросов к репозиторию
   - Данные, возвращаемые методом

#### Тестирование операций Update (Обновление)

1. Откройте соответствующий контроллер в Visual Studio

#### Тестирование операций Delete (Удаление)

### Проверка хранения данных в памяти

1. Откройте файл `Repository/DistrictStatisticsRepository.cs` в Visual Studio
2. Обратите внимание на объявление коллекций для хранения данных:
   ```csharp
   private List<Enterprise> _enterprises = new List<Enterprise>();
   private List<Supplier> _suppliers = new List<Supplier>();
   private List<Supply> _supplies = new List<Supply>();
   ```
3. Установите точки останова в методах репозитория
4. Запустите проект в режиме отладки и выполните различные операции через Swagger UI
5. Когда выполнение достигнет точки останова, проверьте содержимое коллекций:
   - Разверните переменные `_enterprises`, `_suppliers` и `_supplies` в окне "Локальные переменные"
   - Проверьте, что данные корректно добавляются, обновляются и удаляются из коллекций

### Отладка ошибок

Если при тестировании возникают ошибки:

1. Проверьте сообщение об ошибке в ответе API или в окне вывода Visual Studio
2. Установите точки останова в соответствующих методах контроллеров и репозитория
3. Запустите проект в режиме отладки и повторите операцию, вызывающую ошибку
4. Используйте пошаговое выполнение (F10) для отслеживания выполнения кода
5. Проверьте значения переменных и параметров в точках останова
6. Исправьте обнаруженные проблемы в коде

### Проверка результатов через Visual Studio

1. После выполнения всех тестов, установите точку останова в методе `GetAllEnterprises()` контроллера предприятий
2. Запустите проект в режиме отладки и выполните запрос на получение всех предприятий
3. Когда выполнение достигнет точки останова, проверьте содержимое коллекции `_enterprises` в репозитории
4. Повторите аналогичные проверки для поставщиков и поставок

Это позволит убедиться, что все данные корректно хранятся в памяти и доступны для запросов.
