# Система управления статистикой района

## Описание проекта

Данный проект представляет собой систему для статистического управления района, которая хранит и обрабатывает информацию о предприятиях, их поставщиках и поставках сырья/комплектующих.

### Основные сущности

1. **Предприятие (Enterprise)**
   - Регистрационный номер
   - Тип отрасли (сельское хозяйство, транспорт, легкая и тяжелая промышленность, строительство, материально-техническое снабжение)
   - Наименование
   - Адрес
   - Телефон
   - Форма собственности (государственно-федеральная, муниципально-городская, ТОО, частная, акционерная)
   - Количество работающих
   - Общая площадь

2. **Поставщик (Supplier)**
   - Идентификатор
   - Наименование
   - Адрес
   - Телефон

3. **Поставка (Supply)**
   - Идентификатор
   - Связь с предприятием
   - Связь с поставщиком
   - Наименование товара/сырья
   - Количество единиц
   - Дата поставки

### Реализованные запросы

1. Вывод всех сведений о конкретном предприятии по регистрационному номеру
2. Вывод всех поставщиков, поставивших сырье за заданный период, упорядоченных по названию
3. Вывод количества предприятий, с которыми работает каждый поставщик
4. Вывод информации о количестве поставщиков для каждого типа отрасли и форме собственности
5. Вывод топ 5 предприятий по количеству поставок
6. Вывод информации о поставщиках, поставивших максимальное количество товара за указанный период

## Структура проекта

- **DistrictStatisticsManagement** - основная библиотека классов
  - **Enums** - перечисления (типы отраслей, формы собственности)
  - **Models** - модели данных (предприятие, поставщик, поставка)
  - **Repository** - репозиторий для работы с данными

- **DistrictStatisticsManagement.Tests** - проект с unit-тестами
  - **DistrictStatisticsRepositoryTests.cs** - тесты для проверки запросов

- **DistrictStatisticsManagement.Api** - веб-API проект для доступа к данным через HTTP
  - **Controllers** - контроллеры для обработки HTTP запросов
  - **Properties** - настройки запуска и конфигурации

## Как запустить проект

### Запуск библиотеки и тестов

1. Клонировать репозиторий
2. Открыть решение в Visual Studio
3. Восстановить пакеты NuGet
4. Запустить тесты для проверки работоспособности

### Запуск API

1. Открыть решение в Visual Studio
2. Установить проект `DistrictStatisticsManagement.Api` как стартовый проект (правый клик на проекте -> "Назначить стартовым проектом")
3. Нажать F5 или кнопку "Запустить" для запуска проекта
4. Браузер автоматически откроется на странице Swagger UI (http://localhost:5000/swagger)
5. Инициализировать тестовые данные через эндпоинт `POST /api/DataInitialization/initialize`
6. Использовать API для работы с данными

### Основные эндпоинты API

- **Предприятия**: `/api/Enterprise`
- **Поставщики**: `/api/Supplier`
- **Поставки**: `/api/Supply`
- **Аналитика**: `/api/Analytics`
- **Инициализация данных**: `/api/DataInitialization`

Подробная документация по API доступна в Swagger UI после запуска проекта.
