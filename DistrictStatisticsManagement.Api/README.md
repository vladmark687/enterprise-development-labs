# District Statistics Management API

## Запуск проекта

Если у вас возникает проблема с запуском проекта API через Visual Studio (нет опции "Назначить в качестве запускаемого проекта" или ошибка "Проект, библиотека классов которого имеет тип 'Тип выходных данных', нельзя запустить напрямую"), выполните следующие действия:

### Вариант 1: Запуск через командную строку

1. Откройте командную строку (PowerShell или Command Prompt)
2. Перейдите в директорию проекта API:
   ```
   cd путь\к\DistrictStatisticsManagement.Api
   ```
3. Выполните команду:
   ```
   dotnet run
   ```
4. Откройте браузер и перейдите по адресу: http://localhost:5000/swagger

### Вариант 2: Настройка Visual Studio

1. Щелкните правой кнопкой мыши на решении в Solution Explorer
2. Выберите "Свойства"
3. В открывшемся окне выберите "Общие свойства" -> "Проект запуска"
4. Выберите "Один запускаемый проект" и укажите "DistrictStatisticsManagement.Api"
5. Нажмите "Применить" и "ОК"

## Использование API

API предоставляет следующие контроллеры:

- **EnterpriseController**: управление предприятиями
- **SupplierController**: управление поставщиками
- **SupplyController**: управление поставками
- **AnalyticsController**: аналитические запросы
- **DataInitializationController**: инициализация тестовых данных

Для тестирования API используйте Swagger UI, доступный по адресу: http://localhost:5000/swagger

### Порядок работы с API

1. Сначала инициализируйте тестовые данные через `/api/DataInitialization/Initialize`
2. Используйте остальные эндпоинты для работы с данными и получения аналитики
3. При необходимости очистите данные через `/api/DataInitialization/ClearData`
